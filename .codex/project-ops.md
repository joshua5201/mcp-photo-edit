# Project Operations

## Commit Policy

- The project lead may commit milestone-approved work on the feature branch.
- Sub-agents may also commit when delegated to do so.
- Commit messages should be meaningful and reviewable by the manager.
- Do not commit unrelated workspace changes just to keep the branch clean.
- Prefer one meaningful commit per milestone or reviewable sub-step.

## Delegation Policy

- Do not share the full chat history with sub-agents.
- Give sub-agents only the minimum context required for their scope.
- Use `.codex` briefs to pass milestone context and constraints.
- The project lead owns milestone direction, plan review, implementation review, and final milestone sign-off before manager review.
